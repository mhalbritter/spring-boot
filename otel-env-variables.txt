## Won't support

* OTEL_CONFIG_FILE
  not available - Needs DeclarativeConfiguration from opentelemetry-sdk-extension-incubator
* OTEL_ENTITIES
  incubating spec, also not supported in OpenTelemetry Java SDK
* OTEL_LOG_LEVEL
  we don't use their logger
* OTEL_EXPORTER_PROMETHEUS_HOST
  we don't use OpenTelemetry's Prometheus
* OTEL_EXPORTER_PROMETHEUS_PORT
  we don't use OpenTelemetry's Prometheus
* OTEL_EXPORTER_OTLP_METRICS_PROTOCOL
  we use Micrometer's OtlpRegistry which only supports http/protobuf
* OTEL_METRIC_EXPORT_TIMEOUT
  We use Micrometer's OtlpRegistry for which we have a timeout, and we don't use a Periodic exporting MetricReader
* OTEL_EXPORTER_ZIPKIN_ENDPOINT
  OpenTelemetry's Zipkin support is deprecated
* OTEL_EXPORTER_ZIPKIN_TIMEOUT
  OpenTelemetry's Zipkin support is deprecated
